# Nyxoshi

Rede social independente, noturna e mobile-first. Um espaço calmo para escrever, seguir e conversar — sem palco emprestado.

## O que já existe

- Contas (Google, X e e-mail/senha)
- Perfil com @, nome e bio
- Publicações, curtidas e comentários
- Seguir, feed “Para você” e “Seguindo”
- Pesquisa, notificações, bloqueio e denúncia

## Stack

TanStack Start, React 19, TypeScript, Tailwind CSS, Postgres (Neon em produção, PGLite no preview), Better Auth e Zod.
